Arclayer / Network

A settlement layer
built on proofs.

Arclayer is a validator network that finalizes transfers in under a second and emits a proof for each one. Below is how the architecture fits together.

Consensus

BFT consensus with leader rotation. Finality lands in a single round; there are no forks by design.

Proven settlement

Every block carries an aggregated proof. A counterparty verifies a transfer without trusting the operator.

Custody

Keys under policy: limits, multi-sig, geo constraints. Private keys never leave the enclave.

Rails

Outbound settlement into local payment systems without bridges — through native operators.

Network specs
Finality
Median 0.4s, p99 0.9s. Single round, no probabilistic confirmation.
Throughput
Up to 14,000 settlements per second on the current validator set, scaling horizontally by shard.
Validators
118 independent operators across 24 jurisdictions. Two-thirds threshold for finalization.
Proofs
Aggregated signatures per block; proof size is constant regardless of transfer count.
